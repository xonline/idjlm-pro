Welcome to IDJLM Pro

This is the legacy Advanced workspace. The primary local workflow is the six-page Library, Review, Categories, Export, Activity, and Settings workspace.

  1. Import a copied test folder — import does not move source files
  2. Review and correct — keep model suggestions separate from human decisions
  3. Preview a write or export — inspect changes before committing them
  4. Restore if needed — verified backups support guarded restore

The optional local audio model is experimental; it does not auto-approve tracks or require a cloud API key.
